# Medical--Landing-page
A comprehensive Medical Health Organization landing page designed as a college project, featuring patient and doctor portals, emergency services, and an integrated AI health assistant.
This repository contains the front-end landing page for a comprehensive Medical Health Organization system, designed as a college project. It serves as the public-facing hub connecting patients, medical professionals, and administrators through a modern, mobile-first interface.  
Key Features
 Patient Features: Includes online appointment booking with available time slots, teleconsultation options, and digital prescription access.  
 Doctor Portal: A dedicated space for doctors to view today's appointments, manage availability, and conduct teleconsultations.  
 Emergency System: Features one-click emergency contacts, ambulance requests, and live emergency department status.  
 Admin Dashboard: Supports appointment analytics, department-wise statistics, and website traffic monitoring.  
 AI Health Assistant: Integrates an AI tool for general health questions and department guidance, with clear notices that it does not replace a doctor.  
 Progressive Web App (PWA): Built with a fully responsive design and future-ready structure for mobile installation.  
 Security & Privacy: Designed with role-based access control, data encryption, and consent management principles.
